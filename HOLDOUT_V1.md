# Frozen holdout v1

This holdout is frozen before running the advanced topology zoo.

Purpose: stress information-flow distinctions without further prompt/threshold tuning.

Cases cover:
- ordinary safe task
- actual override + delayed safe task
- delayed quote closure / meta override

- meta discussion of harmful text
- nested quotation
- mixed meta decoy + actual override

Do not edit case text, expected labels, packet prompts, or guard thresholds in response to these results. Any later design changes require a new holdout version.
